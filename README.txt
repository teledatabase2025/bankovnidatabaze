FINTRON – interní systém finanční analýzy

1. Rozbalte ZIP do samostatné složky.
2. Otevřete soubor index.html v běžném webovém prohlížeči.
3. Kliknutím postupně nahrajte všechny čtyři bankovní výpisy.
4. Po jejich načtení přejděte k finanční analýze.

Web funguje offline a nevyžaduje server ani připojení k internetu.

Aktuální verze:
- úvodní výpisy jsou zobrazené jako kompaktní řádky vhodné i pro mobil,
- tři analytické režimy jsou v samostatných řádcích,
- společné filtry pod nimi platí pro všechny druhy analýzy,
- změna filtru se projeví také v právě otevřeném výsledku.
